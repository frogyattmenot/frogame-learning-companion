# Frogame Learning Companion

An interactive Next.js, React, and TypeScript study guide for the Android Java token-grid game in the parent folder.

## Open in VS Code

Open the `learning-companion` folder in VS Code, then open its terminal and run:

```bash
npm install
npm run dev
```

Visit the local address printed by Next.js (usually `http://localhost:3000`).

## What it includes

- A six-step Java/Android game-building learning path
- Progress that is saved in the browser
- A map of the current Android project files
- Copyable Java code examples
- A responsive, beginner-friendly interface

## Useful commands

```bash
npm run dev    # start the development server
npm run lint   # check code quality
npm run build  # create a production build
```
